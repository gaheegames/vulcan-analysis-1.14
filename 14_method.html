검증

  • 모든 ScriptableObject 레코드는 UnityPy의 바이트 소모 검사(읽은 바이트 = 객체 크기)를 통과한 것만 썼습니다. 검사 실패는 UI·씬 컴포넌트(Movement, Guild_Member_Part 등)뿐입니다.
  • 열거형 라벨은 코드의 인스펙터 표기 문자열(일반 (C)·레어 (R)·영웅 (E)·레전더리 (RD))과 장비 이름(예: '플레어 쉴드'=SD 방패)으로 교차 확인했습니다.
  • 빌드의 데이터 파일 이름이 에셋 GUID라는 점을 저장소의 .meta 파일(플레어 쉴드.asset.meta guid 14bfedda…)로 확인했습니다.
  • 추출한 폰트 10개 모두 0바이트가 아닙니다. 이름 없는 텍스처 10장은 건너뛰었습니다.
  • 페이지의 모든 수치는 prep.py 한 곳에서 계산한 site_data.json에서만 가져옵니다(페이지별 하드코딩 없음).
  • 작업에 참여하지 않은 검토자가 핵심 발견 6건(제작 재료 참조, 128/134 집계, 스토어 설정값, 테스트 서버 주소, 망치 번호, 골드 던전 수치)을 원본 바이트에서 다시 확인했습니다: 5건 확인, 1건 부분 확인(테스트 서버 주소는 난독화 문자열 복호로만 확인). 결과는 reports/verify_independent.md.
  • 별도 검토자가 뒤끝 SDK 인증서 검증 콜백 건(H3)을 libil2cpp.so와 메타데이터로 ISIL을 직접 다시 만들어 확인했습니다: 전역 콜백을 항상 true로 설정하는 지점 3곳, 게임의 Backend.Initialize 호출, 자체 API의 HttpWebRequest 사용, 채팅의 NativeWebSocket 사용 모두 확인. 실제 실행 중 이 코드가 도는지, 안드로이드 IL2CPP의 HttpWebRequest·WebSocket이 이 콜백을 따르는지는 정적 분석으로 정할 수 없어 실기기 확인이 필요합니다. 결과는 reports/verify_independent_h3.md.
  • 헤드리스 Chromium으로 60쪽 전부를 1280px·375px에서 열어 가로 스크롤 0, 깨진 이미지 0, 스크립트 오류 0, 게임 폰트 3종 로딩, 스크롤 진행바 이동, 햄버거 메뉴 열림을 확인했습니다.

분석자가 정한 것

  • 작업은 클라우드 작업 공간에서 했습니다(메모리 7GB). PC는 도구 다운로드와 결과 저장에 썼습니다.
  • 장르는 idle_rpg로 정하고 crafting·hero_collection 등은 태그로 적었습니다.
  • 글꼴: 본문 NotoSansKR(게임 TMP 폰트), 제목 HeirofLightBold(게임 TMP 폰트), 숫자 Roboto-Bold(게임 TMP 폰트). 리포트에 쓴 글자만 남겨 woff2로 줄였습니다.
  • 팔레트: 앱 아이콘 지배색(핏빛 #8F2012, 엠버 #E58055, 골드 #F4BB7A)과 타이틀 화면의 보라빛 어둠을 썼습니다. 등급 색은 게임 UI에서 확인하지 못해 관례적인 회색·파랑·보라·주황으로 정했습니다.
  • 마스코트는 영웅 '알베도' 초상화입니다(다크 판타지 톤과 맞는 판금 기사).
  • Item_Time은 분 단위(1440=24시간)로 읽었고, TBC cost는 루비 가격으로 읽었습니다. 둘 다 추정입니다.
  • 몬스터 이미지는 같은 이름의 스프라이트를 붙였습니다(연결 근거가 이름뿐이라 추정).
